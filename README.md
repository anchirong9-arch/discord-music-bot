# 🎵 안치롱 뮤직봇

디스코드 음성 채널에서 **유튜브 노래를 틀어 주는 봇**입니다.
윈도우에서 `실행하기.bat` 하나만 더블클릭하면 됩니다.

---

## 사용법 (딱 3단계)

### 1️⃣ 봇을 서버에 초대하기
아래 링크를 클릭 → 서버 선택 → **승인** 을 누르면 봇이 서버에 들어옵니다.

```
(여기에 초대 링크를 붙여넣으세요 - 아래 "초대 링크" 참고)
```

> 봇이 이미 서버에 있다면 이 단계는 건너뛰세요.

### 2️⃣ `실행하기.bat` 더블클릭
- 처음 실행하면 **자동으로** 파이썬·FFmpeg 설치 확인, 필요한 패키지 설치까지 다 해 줍니다.
  (처음 한 번은 1~2분 걸려요. 검은 창이 떠 있는 건 정상입니다.)
- 처음 한 번만 **봇 토큰**을 물어봅니다. 붙여넣고 Enter 를 누르면 `.env` 파일이 자동으로 만들어집니다.
- 그러면 바로 봇이 켜집니다. **이 검은 창을 닫으면 봇이 꺼지니** 켜 둔 채로 쓰세요.

### 3️⃣ 디스코드에서 쓰기
디스코드에서 **음성 채널에 들어간 다음**, 채팅창에 이렇게 입력하세요.

```
/재생 아이유 좋은날
/재생 https://youtu.be/dQw4w9WgXcQ
```

끝! 노래가 나옵니다. 🎶

---

## 명령어

| 명령어 | 설명 |
| --- | --- |
| `/재생 <유튜브 링크 또는 검색어>` | 곡을 대기열에 추가하고 재생 |
| `/스킵` | 지금 곡을 건너뛰고 다음 곡 |
| `/일시정지` | 잠깐 멈추기 |
| `/재개` | 멈춘 곡 다시 재생 |
| `/정지` | 재생 멈추고 대기열 비우고 나가기 |
| `/대기열` | 대기열 목록 보기 |
| `/현재곡` | 지금 나오는 곡 보기 |

곡이 끝나면 대기열의 다음 곡이 **자동으로** 재생되고, 대기열이 비면 안내 메시지를 보낸 뒤 대기합니다.
명령을 쓰려면 **먼저 음성 채널에 들어가 있어야** 합니다.

## 자주 묻는 문제

**"노래가 안 나오고 조용해요"**
- 서버 설정 → 채널 권한에서 봇에게 **연결 / 말하기** 권한이 있는지 확인하세요.
- 이 PC의 소리 장치와 상관없이 디스코드로 소리가 나갑니다.

**"봇이 명령어를 못 알아봐요"**
- 봇을 초대할 때 **applications.commands** 권한까지 체크했는지 확인하세요.
- 봇을 켠 뒤 몇 초 기다렸다가 채팅창에 `/` 를 쳐 보세요.

**"토큰이 올바르지 않다고 나와요"**
- 이 폴더의 `.env` 파일을 삭제하고 `실행하기.bat` 를 다시 실행해서 토큰을 새로 넣으세요.
- Discord Developer Portal → Bot → **Reset Token** 으로 새 토큰을 받을 수 있습니다.

**"FFmpeg 을 찾지 못했다고 나와요"**
- `실행하기.bat` 를 다시 실행하면 자동 설치를 안내합니다.
- 관리자 터미널에서 `winget install -e --id Gyan.FFmpeg` 를 실행해도 됩니다.

**"연령 제한 / 비공개 영상이라 안 돼요"**
- 유튜브 정책상 로그인이 필요한 영상은 재생할 수 없습니다. 다른 영상으로 시도해 주세요.

**"Sign in to confirm you're not a bot" / "유튜브가 봇으로 의심해 막았어요"**
유튜브가 이 PC를 로봇으로 볼 때 나오는 메시지입니다. 아래처럼 하면 대부분 해결됩니다.
1. 크롬(또는 엣지)에 **Get cookies.txt LOCALLY** 확장 프로그램을 설치합니다.
2. 브라우저에서 **유튜브에 로그인**한 상태로, 확장 아이콘 → **Export** 를 눌러 내려받습니다.
3. 내려받은 파일 이름을 **`cookies.txt`** 로 바꿔 이 폴더(`bot.py` 옆)에 넣습니다.
4. 봇을 꺼다가(`실행하기.bat` 창 닫기) 다시 실행합니다.

> `cookies.txt` 는 내 유튜브 로그인 정보입니다. **절대 남에게 보내거나 GitHub 에 올리지 마세요.**
> (`.gitignore` 에 이미 넣어 두었습니다.)

## 폴더 구성

```
discord-music-bot/
├── bot.py              봇 본체 (파이썬)
├── 실행하기.bat         윈도우 1클릭 실행 파일
├── requirements.txt    필요한 파이썬 패키지 목록
├── .env.example        토큰 파일 예시
├── .gitignore          .env 등 비밀 파일 제외 설정
└── README.md           이 파일
```

`.env` 는 **절대 다른 사람에게 보내거나 GitHub 에 올리지 마세요.** (봇을 조종할 수 있는 비밀번호입니다.)
`.gitignore` 에 이미 등록되어 있어서 실수로 올라가지 않습니다.

## (선택) 직접 실행하고 싶다면

파이썬과 FFmpeg 이 이미 설치된 경우:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      ← 안에 DISCORD_TOKEN=토큰 입력
python bot.py
```

맥/리눅스에서는 `python3 bot.py` 로 실행하면 됩니다 (`.env` 에 토큰 필요, `ffmpeg` 설치 필요).
